# Frontend System Design — курс подготовки

Локальный курс: HTML-уроки, запускаемая практика, прогресс и интервальные повторения в SQLite.
Зависимостей нет — только Node 22+ (`node:sqlite`, `node:test` и стриппинг типов — всё штатное).

## Запуск

```bash
npm start
```

Открыть <http://localhost:4173>. Порт меняется через переменную `PORT`.

Флаги в скриптах не косметика: на Node 22 `node:sqlite` живёт за `--experimental-sqlite`,
а исполнение `.ts` — за `--experimental-strip-types`. На Node 24+ первый флаг можно убрать.

## Структура

```
MISSION.md                 зачем всё это — договорённости о курсе
course/
  server.mjs               сервер без зависимостей: роадмап, уроки, повторения
  schema.sql               схема базы

  seed-questions.mjs       банк вопросов и микро-задачек по урокам
  seed-practice.mjs        запускаемые упражнения и их чеклисты
  cli.mjs                  консоль преподавателя: оценки, ошибки, отчёт
  db.mjs                   подключение к базе
  lessons/NN-slug.html     содержимое уроков
  public/style.css         оформление
practice/                  упражнения: стартовый код + тесты-контракт
  tools/graph.mjs          анализ графа импортов, на нём держится проверка структуры
  NN-slug/                 README, src/ и *.test.ts одного упражнения

```

## Как проходит занятие

1. Открыть урок на сайте, прочитать, сделать микро-задачки.
2. Сделать упражнение из блока «Практика», если оно есть у этого урока.
3. Прийти в чат: «готов к разбору урока N» или «сдаю упражнение NN».
4. Отвечать на вопросы по памяти. Оценки 0–5 и даты повторов проставляются автоматически.
5. Каждые три урока — мок-собеседование.
6. В начале занятия — то, что накопилось на странице «Повторение».

## Практика

Упражнения лежат в `practice/` и запускаются штатным тест-раннером Node.
Правится только `src/`, тесты — контракт задания.

```bash
npm run practice   # все упражнения разом: красное — то, что ещё не сделано
```

Часть тестов в каждом упражнении зелёная с самого начала — они держат поведение,
чтобы рефакторинг его не сломал. Красные проверяют не вывод функций, а **граф импортов**:
циклы, направление по слоям, пробитый публичный API. Подробности — в `practice/README.md`.

## Команды преподавателя

Через npm (флаги уже проставлены): `npm run course -- <команда>`.

```bash
npm run course -- report                 # сводка прогресса и слабые места
npm run course -- due                    # что пора повторить
npm run course -- questions 1            # вопросы урока с id
npm run course -- grade 3 4 --feedback "путает cohesion и coupling"
npm run course -- mistake 1 "coupling" "сказал, что цель — ноль связей"
npm run course -- status 1 done
npm run course -- practice               # упражнения и их статус
npm run course -- practice 03-leaves done --notes "выбрал параметризацию"
```

## Пересоздать роадмап

Схема и сиды идемпотентны — прогресс не теряется:

```bash
npm run seed
```
