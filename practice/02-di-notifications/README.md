# 02 · Инверсия зависимости без единого класса

**Урок 2 — SOLID без карго-культа. Inversion vs Injection**
**~30 минут**

## Ситуация

Модуль `notifications` умеет слать уведомления. Чтобы это делать, он импортирует
`transport/telegram.ts`. Продукт решил: часть уведомлений уходит в SMS, часть в push,
а в тестах не должно уходить никуда.

Прямо сейчас модуль **знает конкретный транспорт**, поэтому:

- подменить транспорт нельзя, не тронув `notifications`;
- в тесте письмо реально «улетает» в outbox;
- удаление телеграма из проекта требует правок в модуле, который к телеграму отношения не имеет.

## Задача

Сделать так, чтобы `notifications` знал только **форму** транспорта, но не его реализацию,
а связывание происходило в `src/app/composition.ts`.

Ограничения:

- классы не использовать — только функции, фабрики и типы;
- публичное поведение `notifyUser` / `notifyAll` сохранить;
- `src/transport/telegram.ts` и файл с тестами не менять.

## Проверка

```bash
node --no-warnings --experimental-strip-types --test "practice/02-di-notifications/**/*.test.ts"
```

Пять тестов, четыре из них сейчас красные. Тест — это контракт, правится только `src/`.

## Сделано, если

- `notifications` не импортирует `transport` ни прямо, ни через третий модуль;
- есть фабрика `createNotifier({ transport })`, возвращающая `notifyUser` и `notifyAll`;
- реальный транспорт подставлен ровно в одном месте — в корне композиции;
- в тесте транспорт подменяется фейком, и настоящий outbox остаётся пустым.

## Что здесь на самом деле отрабатывается

Разница между **inversion** и **injection**, на которой сыплются на собеседовании.
Injection — «зависимость передали аргументом». Inversion — «направление стрелки развернулось:
теперь не модуль знает про транспорт, а транспорт подходит под требование модуля».
Injection без inversion возможен и бесполезен: можно передать аргументом конкретный
телеграм-клиент и остаться привязанным к нему типом.

После решения будь готов ответить в чате: **где именно в твоём коде развернулась стрелка
и какой тип это зафиксировал.**
