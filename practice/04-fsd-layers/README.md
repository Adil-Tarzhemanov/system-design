# 04 · Слои FSD и правило направления импортов

**Урок 4 — FSD: слои, слайсы, сегменты**
**~30 минут**

## Ситуация

Маленькое приложение, разложенное по шести слоям FSD:

```
app  →  pages  →  widgets  →  features  →  entities  →  shared
```

Стрелка означает «может импортировать». Обратно — нельзя, и через слой вниз можно.
В коде три места, где импорт идёт вверх. Приложение при этом работает: нарушение слоёв
никогда не ломает код сразу, оно ломает возможность что-то переиспользовать или вынуть.

## Задача

Убрать все три нарушения, не сломав поведение.

Приём везде один и тот же — **параметризация вместо похода наверх**: если нижнему слою
нужны данные из верхнего, он не идёт за ними сам, а принимает их аргументом.
Кто выше — тот и знает, что подставить.

Ограничения:

- ни один файл не удалять — все три функции должны остаться живыми и использоваться;
- сигнатуры `render`, `greetingLine`, `login`, `logout` из `app/render.ts` не менять;
- файл с тестами не трогать.

## Проверка

```bash
node --no-warnings --experimental-strip-types --test "practice/04-fsd-layers/**/*.test.ts"
```

Четыре теста: три на поведение (зелёные) и один на слои (красный, показывает список нарушений).

## Сделано, если

- `entities` не знает о `features`;
- `shared` не знает вообще ни о чём;
- `widgets` не знает о `pages` — виджет шапки можно вставить на любую страницу;
- все четыре теста зелёные.

## Что здесь на самом деле отрабатывается

Ответ на вопрос «зачем вообще эти правила импортов, если код и так работает».
Правильный ответ не «так принято в FSD», а конкретный: **каждый импорт вверх превращает
переиспользуемую деталь в деталь одного экрана.** Виджет, который тянет заголовок с главной,
на второй странице покажет заголовок главной — и это выяснится в проде.

Обрати внимание на побочный эффект: после починки `widgets → pages` исчезает и цикл
между ними. Циклы почти никогда не заводят специально — они появляются как следствие
нарушенного направления.

Будь готов ответить в чате: **какое из трёх нарушений опаснее остальных и почему.**
